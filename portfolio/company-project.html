公司官方形象網站

時程 2024/01 — 2024/05
我的角色 設計 + 前端開發
狀態 已上線 · 超過 2.5 年
Wireframe 原生 JS RWD CSS 動畫 自製圖示 形象網站
01   專案概述

從零打造公司轉型後的第一個對外門面

公司原本並非軟體產業，轉型後需要一個全新的官方形象網站，向潛在客戶介紹公司的服務內容與品牌定位。這是一個從零開始的全新建置專案，沒有既有網站可以參考或延續。

這也是我第一個全權負責的完整 RWD 網頁，從 wireframe 規劃、視覺設計、前端開發，到最終上線，全程獨立完成。

2.5 yr 持續對外上線服務中
5 mo 從規劃到上線的開發週期
全端 設計到開發一人包辦
02   問題定義

轉型中的公司，需要一張說得清楚的名片

公司正在從傳統產業轉型為軟體服務商，但對外沒有任何數位存在感。潛在客戶無法透過網路了解公司能提供什麼，業務拓展因此受限。

核心需求是建立一個清楚傳達公司服務內容與品牌形象的官方網站，讓第一次接觸公司的客戶能快速理解公司的定位與能力。

04   設計流程

先確認架構，再進入開發

設計流程以快速驗證大架構為主，用 wireframe 確認各頁面的版型與內容配置後，直接進入前端開發階段。

1
頁面規劃與 Wireframe
列出網站需要的所有頁面，逐一繪製各頁面的大致排版與內容區塊配置，確認整體資訊架構與導航邏輯。
2
視覺風格確立
以公司 LOGO 的色調為基礎延伸出整體配色系統，確保視覺風格與品牌形象一致。
3
自製圖示與動畫發想
導覽列的小圖示全部自行繪製，首頁動畫也由自己發想設計，強化網站的獨特性與品牌識別度。
4
前端開發與上線
以原生 JS 與 CSS 完成完整的 RWD 前端實作，從桌機到手機各斷點均完整支援。
05   視覺設計

從 LOGO 色延伸，自製圖示強化品牌一致性

整體配色以公司 LOGO 的主色調為起點，向外延伸出完整的視覺系統，確保各頁面的風格統一且具品牌識別度。

設計亮點

導覽列的所有小圖示均由自己手繪製作，非使用現成 icon library，讓視覺風格更貼近品牌個性。首頁動畫也從頭發想，為訪客創造第一眼的吸引力。

06   技術實作

純原生開發，從頭到尾不依賴框架

整個網站以原生 JavaScript 與 CSS 完成，未使用任何前端框架或 UI 套件。這個選擇讓我對瀏覽器底層的渲染機制、CSS 排版邏輯、以及 JS DOM 操作有了更深入的掌握。

RWD 的各斷點版型均由自己規劃與實作，手機、平板、桌機版各自優化，確保在所有裝置上的閱讀體驗。
